# Architecture Decision Records

This is the project's decision log — what some teams call `docs/decisions/`. CloudForge uses the more common ADR convention instead of a parallel folder, so there is exactly one place decisions live.

20 decisions are already scoped in `PLAN.md` §6 (ADR-001 … ADR-020), each mapped to the milestone that first implements it. Copy `000-template.md`, fill it in **on the day you actually implement that decision** — not from memory afterward — and commit it in the same commit as the change it describes (`PLAN.md` §18.3).

## Template

```markdown
# ADR-0XX: <title>

**Status:** accepted   **Date:** <YYYY-MM-DD>   **Milestone:** MX

## Context
What problem or choice this addresses.

## Decision
What was chosen.

## Alternatives considered
What else was possible, and why it was rejected.

## Consequences
What this makes easier, harder, or costs.
```

Nothing in this folder exists yet — the table in `PLAN.md` §6 is the plan, these files are the record of when and why each one actually happened.
